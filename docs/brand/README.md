# ArtCraft brand marks

The ArtCraft name, wordmark and logos that upstream LightCraft keeps in this directory are not in
this fork, as [`LICENSE-brand.txt`](LICENSE-brand.txt) requires of a published modified version:
LightCraft for air/OS ships in air/OS images, so it must not carry the ArtCraft Marks or present
itself as an ArtCraft product. This repository credits upstream in plain text only: LightCraft for
air/OS is based on [LightCraft](https://github.com/storytold/lightcraft) by the ArtCraft team.
`LICENSE-brand.txt` is kept unchanged as the record of those terms.
